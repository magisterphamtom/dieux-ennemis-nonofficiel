# Dieux Ennemis (non officiel) — système Foundry VTT

Système **non officiel**, créé par un fan, pour jouer à *Dieux Ennemis* sur [Foundry VTT](https://foundryvtt.com) (version 14).
Il n'est ni affilié ni approuvé par [Les XII Singes](https://www.les12singes.com) ou l'auteur du jeu.

## Contenu
- Fiches de héros, de dieux, de premiers / seconds rôles et de figurants.
- Fenêtres de jet : risques (Dévotion ou Hubris, historique, dés-avantages, difficulté), attaque, initiative.
- Panneau d'actions des dieux : nouveau scénario, autorité, inspiration, miracle, malédiction, soins, cérémonie.
- Suivi des bénédictions (limite d'usage par scénario), des malédictions et des inspirations.

Ce système **ne contient aucun texte, règle détaillée, illustration ni élément d'univers des livres** :
il faut posséder le jeu pour y jouer. Les dieux portent des noms génériques, modifiables dans
*Configuration → Paramètres du système*.

## Installation
Dans Foundry : *Systèmes de jeu → Installer un système*, puis coller l'URL du manifeste :

```
https://github.com/magisterphamtom/dieux-ennemis-nonofficiel/releases/latest/download/system.json
```
